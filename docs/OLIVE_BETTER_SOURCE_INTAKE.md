## 별도 작업 기준

- Probe/Cofa에는 접근하지 않습니다.
- 사용자가 제공한 최신 코드 미리보기를 기능·구조의 기준으로 사용합니다.
- 미리보기에 전문이 없는 300개 상품 데이터와 기존 스크린샷은 원본으로 가장하지 않습니다.

- 실제 외부 LLM 호출은 노출된 키나 미승인 자격정보 없이 수행하지 않습니다. 대신 provider 어댑터의 요청·응답·실패 폐쇄 동작을 결정론적 테스트로 검증합니다.

## 우선 수정 대상

1. 고객 발행 API가 내부 초안·제외 상품을 과도하게 반환하는 문제
2. 반응 API가 상품과 영역의 실제 포함 관계를 확인하지 않는 문제
3. 비어 있거나 잘못된 LLM JSON을 기본 문구로 바꿔 `live`로 오판하는 문제
4. 화면 표시 위주의 smoke를 실제 생성·발행·반응 재적용 E2E로 보강

이 문서는 소스 부재를 성공으로 숨기지 않기 위한 인수 증거이며, 별도 구현의
출처와 한계를 고정합니다.
